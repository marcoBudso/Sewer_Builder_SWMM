# Quick Start

1. Prepare the input GIS layers and terrain model.
2. Draw the proposed pipe alignment.
3. Generate calculated manholes and pipes.
4. Open the Profile Editor.
5. Check invert elevations, excavation depths, pipe diameters and slopes.
6. Add manual nodes from GIS where needed.
7. Generate subcatchments and the SWMM model.
8. Run the simulation and inspect result layers.
