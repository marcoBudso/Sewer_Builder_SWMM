# Contributing

Contributions are welcome.

## Development guidelines

- Keep the plugin compatible with supported QGIS 3.x versions.
- Do not change public layer field names without documenting the migration.
- Use clear English comments and user-facing messages.
- Test changes in QGIS before opening a pull request.
- Keep hydraulic and SWMM terminology consistent across the interface and documentation.

## Pull requests

Please include:

- A clear description of the change.
- QGIS version used for testing.
- Steps to reproduce or validate the change.
- Screenshots for UI changes where useful.
