# Installation

## Install from ZIP

1. Open QGIS.
2. Go to **Plugins → Manage and Install Plugins**.
3. Select **Install from ZIP**.
4. Choose the plugin ZIP from the `release/` folder.
5. Enable **SWMM Sewer Builder**.

## Manual installation

Copy the `SewerSWMMBuilder` folder into your QGIS profile plugin directory and restart QGIS.
